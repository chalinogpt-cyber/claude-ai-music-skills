# 🎙️ Cómo usar estos corridos en Suno

Guía paso a paso para convertir cada archivo de [`songs/`](../songs/) en una canción terminada.

## Paso 1 — Abre el corrido

Elige el corte que quieras en la carpeta `songs/`. Cada archivo trae todo lo necesario:
- **Style Box** (descripción de estilo)
- **Exclude Styles** (lo que NO quieres)
- **Lyrics Box** (la letra con tags)
- **Letra para streaming** (sin tags, para la descripción del video)
- **Notas de pronunciación** y **ajustes recomendados**

## Paso 2 — Configura Suno

1. Entra a [suno.com](https://suno.com) y crea una canción nueva en modo **Custom**.
2. Activa **"Instrumental: Off"** (queremos voz).
3. Selecciona el modelo **V5** o **V5.5**.

## Paso 3 — Pega el estilo

- Copia el contenido del **Style Box** en el campo *Style of Music*.
- Al final, pega también las **Exclude Styles** (si el campo lo permite) o úsalas en el apartado de exclusiones.

## Paso 4 — Pega la letra

- Copia el **Lyrics Box** completo (con los tags como `[Coro]`, `[Verso 1]`, etc.) en el campo *Lyrics*.
- Respeta los trucos de pronunciación (por ejemplo, escribir **"Tree"** para que cante "Tri").

## Paso 5 — Genera y elige

- Genera **2 a 4 tomas**.
- Escucha y elige la que tenga el **coro más coreable** y la instrumentación más clara (tuba, requinto, bajo sexto).
- Si algo no suena bien, vuelve a generar: cada toma es distinta.

## Paso 6 — Publica

- Usa la **letra para streaming** (sin tags) en la descripción de tu video.
- Recuerda: todas las letras son limpias y pensadas para ser **monetizables** (sin groserías ni referencias de narco).

---

## Consejos generales

- **Voz primero:** describir la voz al inicio del Style Box ayuda a que Suno priorice el tipo de interpretación.
- **Menos es más:** si el resultado suena saturado, quita uno o dos instrumentos del Style Box.
- **Contraste dinámico:** los tags como `[Intro - soft requinto]` y `[Coro - tuba kicks in]` ayudan, pero no siempre se respetan al 100%.
- **BPM:** puedes subir o bajar el BPM sugerido para cambiar la energía del corte.
